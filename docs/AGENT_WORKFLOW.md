# Agent workflow

Use the shared [agent claim and execution guide](https://github.com/iconidentify/libva-v4l2_request/blob/avd-fixes/docs/AGENT_WORKFLOW.md).
Its [GitHub issue copy](https://github.com/iconidentify/libva-v4l2_request/issues/8) is also available.
The cross-repository [roadmap index](ROADMAP.md) links workstreams and individual tickets.

Read this repository's [AGENTS.md](../AGENTS.md) and [README.md](../README.md) first.
Those instructions remain in force, including machine checks, installation consent,
shipped-patch constraints, saved work before module unload/reboot, OpenGL output and
reporting setup problems in our own repositories.

Claim one ready leaf ticket with a unique agent/session ID; confirm ownership in the
comments and use an isolated worktree based on `main`. GitHub assignment alone is not
exclusive ownership when agents share an account. Hardware access requires a separate
exclusive guarded run and any applicable explicit authorization. An issue is not consent
to install a kernel/module or reboot this machine.

Completion requires a merged result plus evidence for every acceptance criterion.
Research completion does not establish feature support. Keep blockers and support claims
accurate, and leave a handoff when releasing a claim.
